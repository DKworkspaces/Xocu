how to add nested ai agents 

Layer 1: The Manager Agent (The Brain)
Role: Chief Content Officer.
Task: You give it a raw idea (e.g., "Write a piece about how to fix camera audio hiss"). The Manager fetches your core audience profile from GitHub (/audiences/tech_creatives.md) and creates a unified concept strategy.
Layer 2: The Nested Specialist Agents (The Workers)
YouTube Agent: Ingests the Manager's concept + formats/youtube_script.md. It writes a high-retention script with B-roll cues.
Twitter Agent: Ingests the Manager's concept + formats/twitter_thread.md. It condenses the exact same core value into punchy, character-limited tweets.
Blog Agent: Ingests the Manager's concept + formats/blog_post.md. It expands the points into a long-form, SEO-optimized article.

Layer 3: The Publisher Agent (The Automated Archivist)
Role: Git Webhook Automator.
Task: This agent doesn't write content. It takes the clean text strings generated by Layer 2, formats them into file titles (e.g., 2026-09-14-audio-hiss.md), and uses a GitHub API wrapper to push them straight into your /outputs/ repository folders.
