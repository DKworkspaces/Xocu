HOW TO USE




Trigger Your First Growth Campaign

Now that your factory is built, 
let's turn it on.

Click on the Issues tab at the top 
of your GitHub repository screen.
Click the green New Issue button.

In the Title box, type whatever content
topic you want your team to build today
(e.g., 3 time saving tools for video 
editors). 

Leave the description blank.
Click Submit new issue.






Grab Your Content Prompt
Wait about 30 to 60 seconds on that 
issue page.A automated GitHub Action bot 
will instantly post a comment directly under
your issue.This comment contains a specialized,
data-enriched Mega Prompt stuffed with real
-time keywords it just scraped from the web.
Highlight and copy that entire prompt block, 
then paste it into any free AI chat tool
(like the free versions of ChatGPT, Claude, 
or Gemini).
